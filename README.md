One fortune cookie line for a crypto trader who just got liquidated. It opens with the most classic cookie promise — "a great fortune awaits you" — then turns on the double meaning of "fortune": the prophecy already visited, and left with the trader's margin. Running main.py writes the line to /output/entry.txt.
## Run it
```sh
python3 main.py
```
